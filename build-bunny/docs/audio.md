# Audio — sound effects, music, narration

Build Bunny's audio lives in one provider (`src/ui/sound.tsx`) with three
independent channels, each with its own switch and volume, plus a master
mute. This file records how it behaves, where every sound comes from, and
what a school should know.

## Behaviour (classroom rules)

| Rule | How it is met |
|---|---|
| Off by default | `DEFAULT_AUDIO_PREFS` has every channel off. A fresh device makes no sound until a child or teacher turns something on. |
| Starts only after a user gesture | The `AudioContext` is created lazily and resumed from `pointerdown` / `keydown` / `touchend`, or from the settings tap itself. Nothing autoplays; nothing is even constructed on page load (pinned by `e2e/audio.spec.ts`). |
| iPad Safari | Same gesture-unlock path (`webkitAudioContext` fallback, `touchend` listener). Speech is primed with an empty utterance from the gesture. **Not yet verified on a physical iPad** — see checklist. |
| Instant mute | One tap on the speaker button in every level player (`PlayerSoundControls`). Master mute keeps channel settings so unmuting restores them. |
| Saved per device | `localStorage["bb:audio:v2"]`, never on the server: a shared classroom tablet's volume belongs to that tablet. The older single toggle (`bb:sound`) is migrated on first read. |
| Pause when the tab is hidden | `visibilitychange` suspends the context and cancels speech; visible again resumes if anything is on. |
| Stop when leaving the game area | Music only plays while a screen requests it (`useMusicScene`): home, the map and the level player. Profile/achievements fade it out; leaving the student area closes the context. |
| No overlapping pile-ups | `SfxPlayer` enforces a per-effect minimum gap and at most 6 simultaneous effects; narration cancels the previous utterance. |
| No abrupt volume changes | Every level change is a ramp (`setTargetAtTime`), tracks crossfade over ~1.5 s, effects have soft attacks and exponential releases. |
| No long downloads | There are no audio files. Effects and music are synthesized in the browser; narration uses the device's built-in voices. Nothing is fetched. |
| Important information never sound-only | Every narrated text is on screen; every cue has a visual counterpart (banner, stars, badge). |

## Where every sound comes from (licence)

| Asset | Source | Licence |
|---|---|---|
| All 16 sound effects | Synthesized at call time by `src/ui/audio/sfx.ts` (oscillators + filtered noise). | Original work, part of this repository. |
| All 9 music tracks (map + 8 worlds) | Generated by `src/ui/audio/music.ts`: per-world chord progression, seeded melody, pad/bass/bell/shaker voices, generated reverb impulse. | Original work, part of this repository. |
| Narration voices | The user's own device / browser (`speechSynthesis`), **local voices only**. | Provided by the OS; nothing shipped. |

No third-party samples, loops, recordings or fonts of any kind are used.
There are **no placeholders** — the music that plays is the finished,
generated music. If NITAQ later commissions recorded music, it can replace
the generated tracks behind the same `MusicEngine` interface without
touching any player.

## Music tracks

| Track | Worlds | Character |
|---|---|---|
| `map` | Home, adventure map | Calm C major, sparse melody, bells |
| `meadow` | Bunny Meadow | Bright G major, light shaker |
| `forest` | Logic Forest | D dorian, soft flute-like lead |
| `lab` | Robot Lab | A minor, filtered square arpeggio, ticking shaker |
| `island` | AI Island | F lydian, dreamy bells |
| `desert` | Data Desert | E phrygian-dominant (hijaz colour) on a tonic drone, riq-like shaker |
| `ml` | Machine Learning Lab | C minor, pulsing bass |
| `city` | Code City | Bb major, syncopated bass, upbeat |
| `workshop` | Inventor Island | D major, playful bells |

Levels are measured, not guessed: `e2e/audio-levels.spec.ts` renders every
track and effect offline and asserts no clipping (peak < 0.8), music between
−48 and −18 dB RMS at full channel volume, and effects short and gentle.

## Narration and privacy

- Only `SpeechSynthesisVoice.localService === true` voices are ever used.
  Browser "network" voices (which upload text to be spoken) are excluded
  even when they are the only ones available — the UI then says narration
  is unavailable on this device.
- What is spoken is always authored content: the level story, mission,
  hints, feedback and the success card. Never anything a child typed.
- No audio is recorded; the microphone permission stays denied by the
  Permissions-Policy header.

## Settings UI

- Sidebar → **Sound** opens the panel: mute everything, sound effects,
  music, Robo Bunny's voice (with talking speed), each with a test button
  where a test makes sense.
- Level player → speaker button (mute/unmute) and sliders icon (settings).
- A first tap on the player's speaker when nothing is on turns sound
  **effects** on — never music, which is a deliberate choice made in the panel.
